# H1 全局轨迹与朝向反馈修复

本次仅修改 `SuperMimic_H1-main` 内的文件。验证范围为全部 43 个 H1 动作，使用既有 20000 轮检查点兼容续训 **500 轮**，到 20500 轮结束。后续 4 小时训练的命令见文末；本次不自动启动该长任务。

## 1. 问题来源

旧策略的目标输入为 480 维：10 帧参考关节位置、速度、重力、角速度、航向坐标系线速度和高度。这些特征没有直接提供机器人相对参考轨迹的水平位置和航向误差。即使机器人已经转错方向，策略也缺少相应的纠偏信息。

身体相对位置、姿态奖励会先把参考动作的 XY 位置和航向对齐到机器人。这类奖励有利于学习动作姿态，但不能单独保证世界坐标中的行进路线正确。原本已有全局位置和姿态奖励，只是采用窄范围指数函数，偏离较远时其数值和梯度接近零。

参考重影使用原始世界坐标轨迹，初始姿态也由参考动作设置。因此本次没有旋转重影、修改 CSV/NPZ 坐标、改变关节映射或在推理时替换策略动作。

## 2. 实现

### 相对参考位姿反馈

启用项目已有的 `anchor_obs` 分支，在目标末尾加入：

- 机器人躯干坐标系下的参考躯干相对位置：3 维。
- 相对旋转矩阵前两列：6 维。

目标输入变为 **489 维**。仿真采集和世界模型想象都使用相同定义；有噪声训练时仍沿用原有观测噪声设置。新训练默认启用，`scripts/train_h1.sh` 也显式传入 `--env.anchor-obs`。旧模型播放仍按检查点中保存的输入格式加载。

### 全局轨迹约束

保留原来的八项奖励和右臂修复奖励，额外启用两项：

| 参数 | 数值 | 含义 |
|---|---:|---|
| `rewards.w-planar-drift` | -0.5 | 全局水平位置偏离惩罚 |
| `rewards.planar-drift-scale` | 1.0 m | 位置代价的尺度 |
| `rewards.w-heading` | 0.5 | 宽范围航向奖励 |

位置代价为 `sqrt(1 + (dx² + dy²) / scale²) - 1`。其零点平滑，远距离误差的恢复梯度不会像指数奖励那样迅速消失。航向得分为 `(1 + cos(yaw_robot - yaw_ref)) / 2`，能正确处理 ±π 跨界；它在完全反向处仍有驻点，不能声称任意角度都具有非零梯度。

两项训练约束均作用于 `torso_link` 锚点，按控制周期 0.02 秒缩放。全局评估使用 `pelvis` 根部，并分别统计纯航向角与完整四元数角误差。仿真和想象奖励共用计算函数，避免二者优化目标不一致。

### 旧模型兼容迁移

新增 `src/supermimic/training/anchor_migration.py`，由 `Trainer.load()` 调用：

1. 只接受旧目标维度到“原维度 + 9”的转换，其他不匹配继续严格报错。
2. 给策略目标编码器第一层增加 9 列零权重。
3. 给 Critic 第一层在目标特征末尾插入 9 列零权重，保留后面的环境参数和根部误差特征位置。
4. 对应 Adam 一阶、二阶动量补零，保留原有优化器步数、世界模型、其他网络参数及动作采样状态。

新增输入最初不会改变旧策略的输出，后续更新才学习纠偏。迁移验证中，动作最大差异约 `7.15e-7`，价值输出最大差异约 `9.54e-7`。

### 评估与阶段选择

`src/supermimic/eval/benchmark.py` 保留全部 19 个关节和身体部位指标，增加水平位置、纯航向、水平速度向量、速率和速度方向误差，总计 139 项跟踪指标。

速度方向角仅统计参考和机器人水平速度都超过 0.1 m/s 的帧，并同时报告有效帧比例；双方静止时不把方向角当作有效证据。相对身体误差与全局误差分别报告。

`src/supermimic/training/supervision.py` 补充全局退步检查：不能仅凭存活、完成率或局部关节指标选择更偏离轨迹的模型。误差比较仍需结合动作覆盖率与每个动作的执行长度；不同失败前缀不能直接当成同一条完整轨迹比较。

后续训练的 TensorBoard 新增 `train_tracking/root_planar_position_mae_m` 和 `train_tracking/root_heading_mae_rad`。它们是训练采样时刻的误差，不等同于固定全动作评估。
