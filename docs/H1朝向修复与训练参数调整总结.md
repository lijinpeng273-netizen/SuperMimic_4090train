## 2. 为什么机器人会与参考重影方向不一致

### 2.1 旧策略缺少直接纠偏信息

旧策略的目标输入为 `10 × 48 = 480` 维，包括参考关节位置、速度、重力方向、角速度、参考航向坐标系中的线速度和高度。本体观测主要是关节状态、角速度、重力和历史动作。

这些输入没有直接告诉策略：**机器人现在相对参考轨迹偏到了哪里、朝向相差多少**。水平平移和整体航向漂移可能持续累积。

### 2.2 局部姿态奖励不能单独约束全局路线

原有身体位置、姿态奖励会先把参考身体的 XY 和航向对齐到当前机器人，再比较身体姿态。因此，机器人局部动作相似时仍能得到较好的身体奖励，即使它在世界坐标中走向了不同方向。

原有全局位置、姿态奖励并未缺失，但使用较窄的指数函数，位置尺度为 0.3 m、姿态尺度为 0.4 rad。偏差较大时，得分及恢复梯度迅速变小。

此前检查没有支持“固定旋转了 90°”或“需要交换左右关节”的结论。参考重影展示的是原始世界轨迹；本次修复作用于策略的反馈和训练目标，未通过移动重影掩盖误差。

## 3. 朝向修复如何实现

### 3.1 加入 9 维参考相对位姿

启用已有的 `anchor_obs` 分支，向目标输入末尾添加：

- 参考躯干相对机器人躯干的位置，转换到机器人躯干坐标系：3 维。
- 参考躯干相对机器人躯干的旋转矩阵前两列：6 维。

接入位置：仿真目标观测见 [src/supermimic/envs/tracking_env_cfg.py:120](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/envs/tracking_env_cfg.py:120)；解析相对位姿计算见 [src/supermimic/world_model/heads.py:44](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/world_model/heads.py:44)。

目标维度变为 **489 维**。仿真采集、世界模型想象以及播放加载都使用匹配的定义。当前训练默认与启动脚本均启用 `--env.anchor-obs`；播放时依据检查点恢复输入格式。

### 3.2 增加远距离也能提供纠偏信号的约束

| `rewards.w_planar_drift` | 0 | -0.5 | 惩罚世界坐标中的水平轨迹偏离 | [scripts/train_h1.sh:24](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/scripts/train_h1.sh:24)；字段定义 [src/supermimic/envs/mdp/rewards.py:46](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/envs/mdp/rewards.py:46) |

| `rewards.w_heading` | 0 | 0.5 | 提供宽范围航向得分 | [scripts/train_h1.sh:24](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/scripts/train_h1.sh:24)；字段定义 [src/supermimic/envs/mdp/rewards.py:48](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/envs/mdp/rewards.py:48) |

水平位置代价（公式实现：[src/supermimic/envs/mdp/rewards.py:56](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/envs/mdp/rewards.py:56)）：

```text
cost_xy = sqrt(1 + (dx² + dy²) / scale²) - 1
r_xy = 0.02 × (-0.5) × cost_xy
```

它在零误差处平滑，大误差下仍有恢复方向的梯度。相比只放大全局指数奖励的权重，更适合处理已经偏离数米的情况。

航向得分（公式实现：[src/supermimic/envs/mdp/rewards.py:61](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/envs/mdp/rewards.py:61)）：

```text
score_heading = (1 + cos(yaw_robot - yaw_reference)) / 2
r_heading = 0.02 × 0.5 × score_heading
```

航向得分具有周期性，能处理 ±π 跨界；完全反向处仍有驻点，不能声称任意角度都有非零梯度。

两项训练约束作用于 `torso_link` 锚点，真实仿真与世界模型解析奖励共用计算函数。全局评估则测量 `pelvis` 根部，单独区分纯航向误差和完整三维姿态角误差。

### 3.3 保持旧模型可恢复训练

实现位置：[src/supermimic/training/anchor_migration.py:13](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/training/anchor_migration.py:13)；恢复入口：[src/supermimic/training/loop.py:149](/home/rl-4090/RL_Workspace/ljp_ws/SuperMimic_H1-main/src/supermimic/training/loop.py:149)。

新增迁移逻辑只处理“原目标输入 + 9 维反馈”的明确兼容情形：

1. 策略目标编码器第一层增加 9 列零权重。
2. Critic 第一层在旧目标特征末尾插入 9 列零权重，保留后续环境参数和根部误差特征的顺序。
3. 对应 Adam 一阶、二阶动量补零；保留其他网络权重、世界模型、更新计数及动作采样状态。

迁移刚完成时，新输入的影响为零。验证中动作输出最大差异约 `7.15e-7`，价值输出最大差异约 `9.54e-7`。续训后，新输入权重发生变化，表明策略开始学习利用反馈。

修改参考帧数、历史长度或其他网络结构不属于这项自动迁移支持范围，应单独设计迁移或开始新训练。
